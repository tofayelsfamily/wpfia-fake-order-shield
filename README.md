**WPFIA COD Fraud & Fake Order Shield** is an advanced fraud prevention and checkout security plugin built for WooCommerce stores. It eliminates Cash on Delivery (COD) spam, fake orders, disposable email abuse, and rapid checkout bot attacks without disrupting genuine shoppers.

---

## ✨ Key Features

- **🛡️ Disposable / Temporary Email Blocker:** Blocks 3,000+ known disposable domains (10minutemail, tempmail, guerrillamail, etc.).
- **🚫 Phone Number Blacklist & Formatting:** Blocks repeatedly failed or abusive mobile numbers and enforces valid format.
- **⚡ IP Rate Limiting & Velocity Shield:** Prevents bot checkout flooding by limiting maximum orders per IP within a time window.
- **🛒 High-Risk Order Flagging:** Automatically tags suspicious orders as "Fraud Review" instead of processing them directly.
- **💰 Minimum / Maximum Order Limits for COD:** Protects high-ticket products from risky unpaid Cash on Delivery orders.
- **🚀 100% Local Processing:** Evaluates risk algorithms locally on your server without sending customer data to 3rd-party services.

---

## 🚀 Installation

1. Clone or download:
   ```bash
   git clone https://github.com/tofayelsfamily/wpfia-fake-order-shield.git
   ```
2. Upload `wpfia-fake-order-shield` to `/wp-content/plugins/`.
3. Activate the plugin via **WordPress Admin > Plugins**.
4. Configure fraud rules under **WooCommerce > Fake Order Shield**.
